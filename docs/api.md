# API 接口文档

基础地址：`http://localhost:8080`

## 1. 通用说明

### 1.1 数据格式

- 请求和响应的数据格式为 JSON。
- 请求体中的字段名区分大小写。
- 需要登录的接口通过 Cookie 中的 `session_id` 识别用户。

### 1.2 认证方式

用户注册或登录成功后，服务端会设置 `session_id` Cookie。

Cookie 属性：

| 属性     | 值     |
| -------- | ------ |
| Path     | `/`    |
| Max-Age  | 600 秒 |
| HttpOnly | true   |

需要登录的接口必须携带有效 Cookie。

未登录访问 受保护API 接口时，返回 `401 Unauthorized`。

### 1.3 错误响应格式

发生错误时，服务端返回 JSON：

```
{
  "error": "错误信息"
}
```

## 2. 用户认证

### 2.1 用户注册

- **请求方法：** `POST`
- **请求路径：** `/api/register`
- **是否需要登录：** 否

请求体：

```
{
  "username": "testuser",
  "password": "Test123456"
}
```

| 状态码 | 说明                                         |
| ------ | -------------------------------------------- |
| 201    | 注册成功                                     |
| 400    | 请求格式错误、用户名或密码为空、用户名已存在 |
| 500    | 服务器内部错误                               |

注册成功后：

- 返回新创建的用户信息。
- 设置 `session_id` Cookie。

### 2.2 用户登录

- **请求方法：** `POST`
- **请求路径：** `/api/login`
- **是否需要登录：** 否

请求体：

```
{
  "username": "testuser",
  "password": "Test123456"
}
```

| 状态码 | 说明                           |
| ------ | ------------------------------ |
| 200    | 登录成功                       |
| 400    | 请求格式错误、用户名或密码为空 |
| 401    | 用户名或密码错误               |
| 500    | 服务器内部错误                 |

登录成功后：

- 返回用户信息。
- 设置 `session_id` Cookie。

### 2.3 用户登出

- **请求方法：** `POST`
- **请求路径：** `/api/logout`
- **是否需要登录：** 是

请求参数：无。

| 状态码 | 说明                  |
| ------ | --------------------- |
| 204    | 登出成功              |
| 401    | 未登录或 Session 无效 |
| 500    | 登出失败              |

登出成功后，服务端删除对应 Session，并通过设置过期 Cookie 清除浏览器中的登录凭证。

## 3. 用户资料管理

### 3.1 获取个人资料

- **请求方法：** `GET`
- **请求路径：** `/api/profile`
- **是否需要登录：** 是

请求参数：无。

| 状态码 | 说明           |
| ------ | -------------- |
| 200    | 获取成功       |
| 401    | 身份未验证     |
| 500    | 服务器内部错误 |

### 3.2 获取公开资料

- **请求方法：** `GET`
- **请求路径：** `/api/users/{username}/profile`
- **是否需要登录：** 否

路径参数：

| 参数     | 类型   | 说明   |
| -------- | ------ | ------ |
| username | string | 用户名 |

例如：

```
GET /api/users/testuser/profile
```

成功响应示例：

```
{
  "id": 1,
  "username": "testuser",
  "profile": "Hello!",
  "created_at": "2026-11-12T10:00:00+08:00"
}
```

| 状态码 | 说明           |
| ------ | -------------- |
| 200    | 获取成功       |
| 404    | 用户不存在     |
| 500    | 服务器内部错误 |

### 3.3 修改个人资料

- **请求方法：** `PUT`
- **请求路径：** `/api/profile`
- **是否需要登录：** 是

请求体：

```
{
  "msg": "这是我的个人简介"
}
```

| 状态码 | 说明           |
| ------ | -------------- |
| 200    | 修改成功       |
| 400    | 请求格式错误   |
| 404    | 用户不存在     |
| 500    | 服务器内部错误 |

### 3.4 修改密码

- **请求方法：** `PUT`
- **请求路径：** `/api/password`
- **是否需要登录：** 是

请求体：

```
{
  "msg": "NewPassword123"
}
```

其中 `msg` 表示新密码。

| 状态码 | 说明               |
| ------ | ------------------ |
| 204    | 修改成功           |
| 400    | 请求格式错误       |
| 404    | 用户不存在         |
| 409    | 新密码与旧密码重复 |
| 500    | 服务器内部错误     |

### 3.5 修改用户名

- **请求方法：** `PUT`
- **请求路径：** `/api/username`
- **是否需要登录：** 是

请求体：

```
{
  "msg": "newusername"
}
```

其中 `msg` 表示新用户名。

| 状态码 | 说明           |
| ------ | -------------- |
| 200    | 修改成功       |
| 400    | 请求格式错误   |
| 409    | 用户名已存在   |
| 500    | 服务器内部错误 |

### 3.6 删除账户

- **请求方法：** `DELETE`
- **请求路径：** `/api/user`
- **是否需要登录：** 是

请求参数：无。

| 状态码 | 说明           |
| ------ | -------------- |
| 204    | 删除成功       |
| 500    | 服务器内部错误 |

删除账户后，与该用户关联的 Todo 数据会通过数据库外键级联删除。

## 4. Todo 管理

以下接口均需要登录。

### 4.1 获取 Todo 列表

- **请求方法：** `GET`
- **请求路径：** `/api/todos`

请求参数：无。

成功响应示例：

```
[
  {
    "id": 1,
    "title": "学习 Go",
    "content": "完成 Todo 项目",
    "completed": false,
    "created_at": "2026-11-12T10:00:00+08:00",
    "updated_at": "2026-11-12T10:00:00+08:00"
  }
]
```

| 状态码 | 说明                  |
| ------ | --------------------- |
| 200    | 获取成功              |
| 401    | 未登录或 Session 无效 |
| 500    | 服务器内部错误        |

### 4.2 创建 Todo

- **请求方法：** `POST`
- **请求路径：** `/api/todos`

请求体：

```
{
  "title": "学习 Go",
  "content": "完成 Todo 项目",
  "completed": false
}
```

| 字段      | 类型    | 说明      |
| --------- | ------- | --------- |
| title     | string  | Todo 标题 |
| content   | string  | Todo 内容 |
| completed | boolean | 是否完成  |

| 状态码 | 说明                    |
| ------ | ----------------------- |
| 201    | 创建成功                |
| 400    | JSON 格式错误或内容为空 |
| 401    | 未登录或 Session 无效   |
| 500    | 服务器内部错误          |

创建成功后返回新创建的 Todo 数据。

### 4.3 获取 Todo 详情

- **请求方法：** `GET`
- **请求路径：** `/api/todos/{id}`

路径参数：

| 参数 | 类型    | 说明    |
| ---- | ------- | ------- |
| id   | integer | Todo ID |

例如：

```
GET /api/todos/1
```

| 状态码 | 说明                  |
| ------ | --------------------- |
| 200    | 获取成功              |
| 400    | ID 格式错误           |
| 401    | 未登录或 Session 无效 |
| 404    | Todo 不存在           |
| 500    | 服务器内部错误        |

### 4.4 更新 Todo

- **请求方法：** `PUT`
- **请求路径：** `/api/todos/{id}`

请求体：

```
{
  "title": "学习 Go",
  "content": "完成 Todo 项目测试",
  "completed": true
}
```

| 状态码 | 说明                  |
| ------ | --------------------- |
| 204    | 更新成功              |
| 400    | ID 或 JSON 格式错误   |
| 401    | 未登录或 Session 无效 |
| 404    | Todo 不存在           |
| 500    | 服务器内部错误        |

### 4.5 删除 Todo

- **请求方法：** `DELETE`
- **请求路径：** `/api/todos/{id}`

例如：

```
DELETE /api/todos/1
```

| 状态码 | 说明           |
| ------ | -------------- |
| 204    | 删除成功       |
| 400    | ID 格式错误    |
| 401    | 未授权         |
| 404    | Todo 不存在    |
| 500    | 服务器内部错误 |

## 5. 数据结构

### 5.1 Todo

| 字段      | 类型      | JSON 字段名 | 说明     |
| --------- | --------- | ----------- | -------- |
| ID        | int       | id          | Todo ID  |
| Title     | string    | title       | 标题     |
| Content   | string    | content     | 内容     |
| Completed | bool      | completed   | 完成状态 |
| CreatedAt | time.Time | created_at  | 创建时间 |
| UpdatedAt | time.Time | updated_at  | 更新时间 |

### 5.2 用户资料

| 字段      | 类型      | JSON 字段名 | 说明     |
| --------- | --------- | ----------- | -------- |
| ID        | int       | id          | 用户 ID  |
| Username  | string    | username    | 用户名   |
| Profile   | string    | profile     | 个人资料 |
| CreatedAt | time.Time | created_at  | 创建时间 |

密码哈希不会通过 JSON 响应返回。

### 5.3 Msg

```
{
  "msg": "需要提交的内容"
}
```

用于修改个人资料、密码和用户名等接口。
